## 🌟 About the Project

The **Fire Type Management System** is a comprehensive, centralized platform designed to monitor, track, and manage fire-related incidents and emergency resources. Built for modern firefighting teams and safety personnel, this system ensures rapid response times, optimal resource allocation, and real-time environmental monitoring.

Whether you are tracking thermal anomalies or managing firefighter dispatch logs, this dashboard provides the clarity and control needed in critical moments.

---

## ✨ Key Features

- **🔥 Thermal Watch Dashboard:** Real-time monitoring of temperature spikes and potential fire hazards (`thermalwatch_dashboard.html`).
- **👨‍🚒 Personnel Management:** Track active firefighters, their current assignments, and fatigue levels.
- **🗺️ Incident Mapping:** Interactive geographic visualization of active fire zones and safe routes.
- **🚨 Automated Alerts:** SMS and email notification system for rapid deployment when thermal thresholds are breached.
- **📊 Analytics & Reporting:** Generate post-incident reports to analyze response efficiency and equipment usage.

## 💻 Technologies Used

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Python / Node.js (Planned)
- **Version Control:** Git & GitHub
- **Other:** API integrations for weather and thermal imaging sensors

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

You will need the following installed on your machine:
- A modern web browser (Chrome, Firefox, Edge)
- [Git](https://git-scm.com/) installed and configured (User name and email set up)
- A code editor (like Visual Studio Code)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/project-fire.git
   ```
2. **Navigate into the project directory:**
   ```bash
   cd project-fire
   ```
3. **Open the project in your editor:**
   ```bash
   code .
   ```

## 🛠️ Usage

To view the current dashboard, simply locate the `thermalwatch_dashboard.html` file in your project folder and double-click it to open it in your default web browser. 

For development, it is recommended to use a tool like **Live Server** in VS Code to see your changes update automatically as you edit the HTML and CSS.
